# 设计规范 — 奶龙德州扑克

## 一、主题定位

以"奶龙"（Nailong）为核心 IP 形象，打造一款**可爱、轻松、有趣**的德州扑克游戏。

- 关键词：圆润、温暖、活力、可爱
- 情绪传达：轻松娱乐，不严肃，零赌博暗示
- 整体风格：扁平化 + 轻拟物质感，圆角卡片，柔和阴影

## 三、字体

- **中文**：「站酷快乐体」或系统圆体 fallback → `"ZCOOL KuaiLe", "PingFang SC", "Microsoft YaHei", sans-serif`
- **英文/数字**：`"Fredoka One", "Comic Sans MS", cursive`（可爱圆体感）
- **字号阶梯**：12px / 14px / 16px / 20px / 28px / 36px

> 小程序兼容方案：优先使用系统字体，自定义字体通过 CSS `@font-face` 按需加载。

## 四、组件规范

### 4.1 扑克牌

- 尺寸：宽 70px × 高 100px（手机）/ 宽 100px × 高 140px（PC）
- 圆角：10px
- 牌面：白色底 + 花色红/黑色 + 角标 + 中央花色符号
- 牌背：奶龙黄底 + 中央奶龙简笔头像 + 龙鳞暗纹
- 悬停效果：上浮 4px + 阴影加深
- 选中效果：上浮 8px + 奶龙黄色发光边框

### 4.2 筹码

- 形状：正圆形，直径 40px（默认）
- 样式：金色渐变底 + 龙鳞纹理 + 面值居中
- 面值等级色：
  - 1/5 → 白色
  - 10/25 → 浅金
  - 50/100 → 金色
  - 500 → 金色 + 紫边
  - 1000 → 金色 + 红边
- 动画：堆叠 → 飞入底池（贝塞尔曲线轨迹）

### 4.3 按钮

- 大按钮（主操作）：高 48px，圆角 24px，奶龙黄底 + 深棕文字
- 中等按钮：高 36px，圆角 18px
- 小按钮：高 28px，圆角 14px
- 操作栏按钮配色：
  - Fold：灰/红色 `#EF5350`
  - Check：奶龙黄 `#FFD76D`
  - Call：嫩绿 `#8BC34A`
  - Raise：橙粉 `#FF8A65`
  - All-in：渐变红橙

### 4.4 奶龙头像

- 圆形头像，带龙角装饰边框
- 预设表情：
  - 😊 默认开心
  - 🤔 思考中（轮到操作时）
  - 😎 自信（加注/All-in 时）
  - 🏆 胜利（赢得底池时）
  - 😢 失落（输掉时）
- 尺寸：60px（牌桌座位）/ 40px（列表）

### 4.5 计时器

- 圆环形进度条，15 秒倒计时
- 前 10 秒奶龙黄色，5 秒内渐变为红色
- 最后 3 秒脉冲动画（放大缩小）

### 4.6 房间码

- 大号数字显示（36px），深色底 + 亮色文字
- 每两位数字一组分隔（如 "12 34 56"）
- 一键复制按钮（clipboard API）

## 五、动画规范

| 动画 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 发牌 | 300ms | ease-out | 牌从中心飞向玩家位置 |
| 翻牌 | 200ms | ease-in-out | 3D rotateY 从背面到正面 |
| 筹码移动 | 400ms | cubic-bezier(.25,.1,.25,1) | 弧线轨迹飞入底池 |
| 公共牌揭示 | 300ms/张 | ease-out + 延迟 | Flop 三张依次揭示 |
| 按钮 hover | 150ms | ease | 微上浮 + 阴影 |
| 倒计时脉冲 | 500ms | ease-in-out | 最后 3 秒循环 |
| 赢家高亮 | 600ms | ease | 金色光晕闪烁 |

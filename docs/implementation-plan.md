# 实施计划 — 奶龙德州扑克

## 阶段总览

| 阶段 | 内容 | 预计用时 | 依赖 |
|------|------|---------|------|
| 1 | 项目初始化 + 引擎核心 | 2~3 天 | — |
| 2 | AI 引擎 + 单人本地模式 | 2~3 天 | 阶段 1 |
| 3 | 服务端 + 好友对战 | 2~3 天 | 阶段 1, 2 |
| 4 | 奶龙主题 UI 完善 | 1~2 天 | 阶段 2 |

## 阶段 1：项目初始化 + 游戏引擎核心

### 1.1 Monorepo 初始化
- [ ] 创建根 `package.json`，配置 npm workspaces
- [ ] `packages/engine/` 目录 + `package.json` + `tsconfig.json`
- [ ] `client/` 目录：Vite + React + TypeScript 项目
- [ ] `server/` 目录：Node.js + Express + TypeScript 项目
- [ ] 安装各项目依赖

### 1.2 引擎类型定义 (`types.ts`)
- [ ] `Suit` 枚举 (4 花色)
- [ ] `Rank` 枚举 (2~A)
- [ ] `Card` 接口
- [ ] `HandType` 枚举 (高牌~皇家同花顺)
- [ ] `HandRank` 接口 (手牌评估结果)
- [ ] `GamePhase` 枚举
- [ ] `ActionType` 枚举
- [ ] `PlayerState` 接口
- [ ] `GameState` 接口

### 1.3 牌组操作 (`deck.ts`)
- [ ] `createDeck()` — 创建标准 52 张牌
- [ ] `shuffle()` — Fisher-Yates 洗牌
- [ ] `deal()` — 发指定数量牌
- [ ] 单元测试

### 1.4 手牌评估器 (`evaluator.ts`)
- [ ] 同花检测
- [ ] 顺子检测
- [ ] 对子/三条/四条检测
- [ ] 7 选 5 最佳组合查找
- [ ] 同等级下的 kicker 比较
- [ ] `compareHands()` — 多手牌比较
- [ ] 单元测试（覆盖所有 10 种牌型 + 边界情况）

### 1.5 游戏状态机 (`game-state.ts`)
- [ ] `createGameState()` — 初始化游戏
- [ ] `startHand()` — 开始一手牌
- [ ] `processAction()` — 处理玩家行动
- [ ] `nextPhase()` — 推进游戏阶段
- [ ] `determineWinners()` — 判定赢家
- [ ] 状态事件回调
- [ ] 单元测试

### 1.6 下注逻辑 (`betting.ts`)
- [ ] 获取当前玩家合法操作列表
- [ ] 最小/最大下注额计算
- [ ] 大盲/小盲强制下注
- [ ] 单元测试

### 1.7 底池管理 (`pot.ts`)
- [ ] 主池计算
- [ ] 边池创建与分配（All-in 场景）
- [ ] 结算分配
- [ ] 单元测试

**验证标准**：`cd packages/engine && npx vitest` 所有测试通过

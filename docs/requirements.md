# 需求文档 — 奶龙德州扑克

## 一、游戏概述

一款以"奶龙"为主题形象的德州扑克游戏。玩家可与 AI 对战或通过房间码邀请好友对战。Web H5 先行，后续移植微信小程序。

## 二、核心功能

### 2.1 游戏模式

| 模式 | 说明 |
|------|------|
| 人机对战 | 单人 + N 个 AI 玩家，AI 分三个难度等级 |
| 好友对战 | 房主创建房间 → 生成 6 位房间码 → 好友输入房间码加入 → 房主开始游戏 |

### 2.2 房间系统

- **创建房间**：房主设置初始筹码（每人，默认 1000）、AI 数量与难度
- **加入房间**：输入 6 位数字房间码
- **房间管理**：显示在线玩家列表、AI 玩家列表，房主可踢出 AI / 调整座位
- **人数要求**：最少 2 人开局，最多 9 人一桌（含 AI 和真人）

### 2.3 德州扑克规则

标准德州扑克（No-Limit Texas Hold'em）规则：

**游戏流程**：
1. **Pre-flop**：每人发 2 张底牌 → 小盲/大盲强制下注 → 第一轮下注
2. **Flop**：发 3 张公共牌 → 第二轮下注
3. **Turn**：发第 4 张公共牌 → 第三轮下注
4. **River**：发第 5 张公共牌 → 第四轮下注
5. **Showdown**：剩余玩家比牌 → 赢家收底池

**玩家操作**：
- Check（过牌）：无人下注时可选择
- Call（跟注）：跟上当前最高下注额
- Raise（加注）：在跟注基础上额外加注
- Fold（弃牌）：放弃本局，已投入筹码不返还
- All-in（全押）：押上所有剩余筹码

**边池规则**：
- 当某玩家 All-in 且筹码少于当前下注额时，主池由所有玩家竞争，超出部分形成边池
- 边池仅由筹码足够覆盖的玩家竞争

**手牌排名**（从高到低）：
1. 皇家同花顺 (Royal Flush)
2. 同花顺 (Straight Flush)
3. 四条 (Four of a Kind)
4. 葫芦 (Full House)
5. 同花 (Flush)
6. 顺子 (Straight)
7. 三条 (Three of a Kind)
8. 两对 (Two Pair)
9. 一对 (One Pair)
10. 高牌 (High Card)

### 2.4 筹码系统

- 每局开始前，各玩家设定初始虚拟筹码（默认 1000，可自定义）
- 筹码为 0 即被淘汰出局，可在旁观模式观看剩余对局
- 盲注结构：小盲 = 大盲 / 2，大盲初始默认 10
- 盲注递增（可选）：每 N 局/N 分钟后盲注翻倍

### 2.5 AI 难度

| 难度 | 名称 | 行为特征 |
|------|------|---------|
| 简单 | 🟢 新手龙 | 基于手牌强度做基本判断，很少诈唬，被动跟注为主 |
| 中等 | 🟡 机灵龙 | 计算底池赔率，有位置意识，偶尔诈唬 |
| 困难 | 🔴 智者龙 | 手牌范围分析，胜率估算，合理化诈唬频率，半诈唬 |

## 三、界面需求

### 3.1 页面清单

| 页面 | 功能 |
|------|------|
| 首页大厅 | 创建房间 / 加入房间 / 人机对战入口、昵称设置 |
| 房间等待页 | 玩家列表、房间码展示、房主设置面板、开始按钮 |
| 牌桌游戏页 | 核心游戏界面 — 牌桌、玩家座位、手牌、公共牌、操作栏、底池、筹码 |
| 结算页 | 本局赢家、各玩家手牌展示、筹码变化、下一局 / 退出按钮 |

### 3.2 牌桌布局

```
        [AI 2]    [AI 3]
   [AI 1]              [AI 4 / 玩家]
        [公共牌区域]
        [底池显示]
        [玩家手牌]
   [操作栏: Fold / Check / Call / Raise]
```

## 四、非功能需求

- **可玩人数**：1 真人 + AI，或 2~9 真人混合 AI
- **响应式**：适配 PC（1280px+）、平板（768px+）、手机（375px+）
- **实时性**：好友对战中操作延迟 < 500ms
- **可迁移性**：代码结构支持最小成本迁移到微信小程序
